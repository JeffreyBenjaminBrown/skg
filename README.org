* to understand the code
The server is written in Rust. It builds the graph from the user's plaintext
=.skg= files and maintains a Tantivy search index. There are clients for Emacs
(in Emacs Lisp) and Neovim (in Lua). One server process has one retained
interactive user and accepts only one interactive client connection at a time.

The API, the view metadata format, and the .skg file format are described in [[./api-and-formats.md][api-and-formats.md]].
