* to understand the code
The server and its graph are written in Rust. The =.skg= files are
authoritative; the server builds an immutable in-memory graph and a derived
Tantivy search index from them. Clients exist for Emacs and Neovim, and the
TCP protocol is editor-independent.

The API, the view metadata format, and the .skg file format are described in [[./api-and-formats.md][api-and-formats.md]].
