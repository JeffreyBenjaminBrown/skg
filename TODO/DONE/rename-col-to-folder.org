#+TITLE: Audit for renaming collection / col viewnodes to folder

* Scope and proposed rule
This audits the active code, tests, fixtures, protocol, clients, and prose for
the language change recorded in =TODO.org=: “folder viewnode” instead of
“col”.  The intended mechanical rule is:

** collection, when it means the folder viewnode concept
-> folder

** col, when it abbreviates the folder viewnode concept
-> folder

Case and separators should follow the surrounding language: =PartnerCol= ->
=PartnerFolder=, =partner_col= -> =partner_folder=, =partnerCol= ->
=partnerFolder=, and =partner-col= -> =partner-folder=.

I excluded =TODO/= (apart from this new report), =my-dot-claude/=,
=data/**/*.skg=, generated and hidden state, =_burying/=, every =abandoned/=
directory, =docs/orphaned/=, =docs/OVERVIEW-old.org=, and =org-exports/=.
I did inspect the active source, both clients, tests (including test =.skg=
fixtures), tools, top-level documentation, =docs/=, =coding-advice/=,
=windows/=, =example-data/=, and non-obsolete =thoughts/= material.

The existing filesystem sense of “folder” (data folder, owned folder,
Tantivy folder, and so on) remains unchanged.  It is distinguishable from a
folder / scaffold viewnode by context.

** =CollectionPair= / =CollectionReport= in =tools/validate-org-roam-import=

** ordinary English “a collection of ...”
Keep generic uses such as “a collection of =.skg= files,” “a collection of
documents,” “a collection of paths,” “a collection of atomic functions,” and
“whole collections of notes.”  They do not name the folder-viewnode concept.

** =ViewNodeLineCol=, =divide_into_viewNodeLineCols=, and =linecol_to_viewnode=

should not become =ViewNodeLineFolder=.  A separate clarity cleanup could use
=ViewNodeLines=, =divide_into_viewNodeLines=, and =viewNodeLines_to_viewnode=,
but it is not required by this migration.

** cursor/source columns
Keep Lua/Rust names such as =col=, =start_col=, =end_col=, =title_col=,
=point_column=, and =target_column= when they are numeric text coordinates.

** prefixes that merely contain the letters “col”

and =protocol= names and prose.

** references to excluded historical paths

keep those path components verbatim so the links do not break; only rewrite

* Verification census for the eventual implementation
After the compiler-guided rename and focused client tests, search the audited
surface for the old public atoms, =(col ...)=, command families, type names,
domain compounds containing =col=, and domain uses of “collection.”  Any
remaining hit should fall into the explicit non-target list above or an
excluded historical/generated path.  Then run Rust all-target checks, the
Rust suite, Emacs tests, Neovim tests, and integration tests because this
crosses the serialized protocol and both clients.
