Almost nothing. Leaks are judged on owned recorders only (done). A node

owned and a foreign repo never fold together. The default relRepo for a

the repo restriction ("show through X"), which can hide a foreign repo

**** The natural structure
Two things in the config instead of one list with a rule: an ordered
list of the repos you own (the privacy ladder, as now, but only yours),
and a set of foreign repos you read, with no order among them or against
yours. The restriction picks a rung of your ladder; whether foreign repos
are shown is a separate toggle (all or none, or per repo), not a rung.

check that enforces it goes, the manifest no longer orders your repos
against anyone else's, and two teammates' configs cannot disagree,
because they never say anything about each other's order. The leak and
telescope code need no change; they already behave this way.
