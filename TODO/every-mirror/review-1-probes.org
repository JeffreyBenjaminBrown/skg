* How this was run
On 2026-11-16, after slice 9 (HEAD '1144a129'), with 'target/debug/skg'
('cargo build --bin skg') and isolated servers on ports 24800 to 24804,
each on scratch data under 'tests/results/every-mirror/probes-plan1/'.
No full test suite was running. The live servers on 1730 and 1761 were
never touched. Every scratch server was stopped by its PID and its port
was confirmed free afterwards. The scratch data has been deleted.
What stays is under 'tests/results/every-mirror/probes-plan1/':
- 'transcripts/fixtures-old-format/{s1,s2,s3}': the fixtures as
  written, in the old format ('subscribesTo', 'overrides',
  'hidesFromSubs'), with their configs.
- 'transcripts/sN-migrate.txt': the migration tool's output on each
  scratch copy.
- 'transcripts/sN-final-skg-files.txt': every '.skg' file at the end.
- 'transcripts/s1/', 's2/', 's3/': each view, edit and save. A step
  folder holds 'before.compact.org' and 'before.full.org' (what the
  server drew), 'sent.compact.org' (the edited buffer) and 'save.out'
  (the save report and the server's answer), plus the rerendered view.
- 'bin/': the helper scripts ('lib.sh', 'step.sh', and 'wire.py' for
  raw socket requests).

The fixtures:
- s1 is for ranking. The skgrepos are owned 'pub' and 'priv', foreign
  'bob', and foreign 'alice' and 'alicepriv'. 'alice' and 'alicepriv'
  are one owner, chained by 'OTHER_SKGREPO_DEPENDENCIES.toml', with
  'alicepriv' the more private. They are declared in the order pub,
  bob, alice, alicepriv, priv. Root 'P' (pub) contains n1, n2, n3, n6,
  n7, n8, n10, m11a and n12.
- s2 is for the forks folder and the rules. It has owned 'main' and
  foreign 'fr', and 'main' is a gitrepo with the migrated fixture
  committed. N forks [E1, M1, E2]. M1 forks N. R1 forks N and E1. R2
  forks N. Z forks foreign F. C contains N. There is also a foreign
  ForkerContained pair in each direction (oE/fR and oR/fE).
- s3 is for the old HEAD and the restriction. It has owned 'pub' and
  'priv', each a gitrepo whose HEAD is in the old format. A (pub) and
  B (priv) fork each other.
