** 1. 'at reload', skg-lens.el:187 -- cheap
Bare "reload" already has two meanings: the server rereading
changed '.skg' files ('server/repo_watch/reload.rs',
docs/COMMANDS.org:65) and the client's 'skg-reload'. It is also
inaccurate; see C1 below. Say "'skg-reload'" or drop it.
** 2. "hot reload" beside "reload" -- cheap doc; rename unwise

(cargo-watch rebuilds and restarts the server). Confusible with
the server's file reload ("the server reloads files",
COMMANDS.org:25). The option is agreed, so keep it; a glossary
entry, or "reload" added to names.org's never-bare list (hot /
file / client reload), closes the gap.
