* Vocabulary
- 'baseline': a buffer's text as the server last drew it, which
  the client keeps and sends with a save ('docs/glossary.org',
  "baseline, outdated, untouched, stale", which slice 1 renames).
- 'the baseline's copy' of a graphnode: the supplemented Save
  instruction the baseline yields for it; 'the buffer's copy':
  the one the saved text yields.
- 'stale' (after slice 1; "outdated" before it): a graphnode
  whose baseline copy differs from the graph. The graph changed
  it under the buffer.
- 'edited' and 'unedited' (after slice 1; "untouched" before it
  for the latter): whether the buffer's copy of a graphnode
  differs from the baseline's copy. The user changed it in the
  buffer, or did not.
- 'edited stale graphnode' (before slice 1 just "stale"): one the
  save refuses for, since writing the user's edit would discard
  the graph's change. 'unedited stale graphnode' (before slice 1
  "untouched outdated"): one the save leaves as the graph has it,
  with a warning.
