** Changes to the plan's envisioned order.
- Archive-root validation was implemented alongside the first shared identity
  types, before the client archive writer.  Every later archive and handshake
  path now has one validated config fact to consume.

** what's imperfect about what's done
- The census currently reconstructs only live view forests; recipes, attached
  workflows and stale-state detail still need the fuller descriptor schema.
- Older foreground rerender streams still need to be routed through the same
  exact application/ACK authority used by retained collateral offers.
- The archive bootstrap is complete, but store selection, final node-evidence
  transfer, per-view disposition and terminal archive finalization are still
  in progress; a verified initial archive intentionally leaves its epoch lock
  installed until those later phases are durable.
- Attached workflow parentage is not present in the current census schema, so
  workflow buffers are classified conservatively (dirty ones are interrupted,
  clean ones close) rather than being settled with their parent.  The durable
  settlement inventory and ACK gate are in place, but clients do not yet apply
  or acknowledge these records.

** choices determining the future
- None.  The Undo Tree discovery is resolved by the agreed fail-closed active-
  mode check; merely having the package installed has no effect.
