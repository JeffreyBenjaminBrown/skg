* Refactoring for dev: 'server/diff_view/', 'server/git_ops/', 'server/graph_straddle/'
  The territory: the diff view's server side, the git layer under it,
  and the graph straddle both stand on. No top-level file of 'server/'
  belongs to it. The diff view's handlers in 'server/serve/handlers/'
  ('diff_view.rs', 'extend_diff_view.rs', 'titles_by_gnids.rs') belong
  to 'server/serve/'. The focused tests are 'bash/nextest.sh --lib
  --test grouped_unit --test grouped_repos' (about a minute warm);
  add '--test grouped_saves' when touching what validation reads
  ('named_leaf_set.rs').

  The territory was already well factored: short functions, each with
  a comment, and 'docs/diff-view.org' cites many of them by file, so
  moving a cited function means changing its note in 'skg-system/' in
  the same commit.
