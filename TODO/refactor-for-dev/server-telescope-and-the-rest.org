* Refactoring for dev: 'server/telescope/', the search code, 'main.rs' and the rest
  The territory: 'server/telescope/', 'server/repo_watch/',
  'server/skgrepo_sets.rs', 'server/prominence.rs', the text search
  ('server/serve/handlers/text_search.rs' and 'text_search/', and the
  search side of 'server/dbs/tantivy.rs' and 'dbs/tantivy/search.rs'),
  'server/main.rs', 'server/subcommands.rs', and the top-level files
  of 'server/' no other handoff file claims ('attribution.rs',
  'receipt.rs', 'metadata_canon.rs', 'org_to_text.rs',

  'delete_references_to_absent_node.rs', 'body_view_escape.rs',
  'consts.rs', 'sexp_string.rs', 'util.rs'). The import and export
  code ('export_org.rs', 'import_org_roam*', 'import_md_and_org/',
  'obsidian/') is not part of it, though 'main.rs' calls into it.
  The Rust tests are grouped into five binaries ('grouped_unit',
  'grouped_views', ...), so '--test NAME' with a file's name fails;
  run 'bash/nextest.sh' whole (about fifteen seconds warm, a minute
  cold). Every refactor below was checked that way, and by the whole
  suite before merge.
