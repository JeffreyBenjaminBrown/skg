****** DONE Claude says: ghosts anywhere; drawn only in diff mode
Not quite. What is diff-only is the goal: only the diff view
draws a ghost that the buffer does not yet show. But a ghost
can stand in any view, because the refresh never deletes a
headline with text: when a node vanishes, each occurrence of
it is re-kinded in place into a ghost and kept until you
tombstone it, whether the deletion happened in this buffer
(a delete request) or in another. That is your "left in
place" rule, and it does not depend on the mode.
An unknown arises anywhere too, but differently: the refresh
draws one wherever a parent's list names an ID that no node
answers to, since the list warrants a member there and the
headline must say so without lying.
A root is neither case's natural home, so the ID rule you
chose decides it: the graph has the node, an occurrence; its
parent names it, an unknown; it has text to show, a ghost;
none of those, a tombstone. A root's parent is the buffer
root, which names nothing, so the second clause never holds
for a root; the third does, since the buffer shows the old
title and body. So a root whose node vanished is a ghost in
every view, precarious or, when HEAD has the node, restorable;
and it is never an unknown, in the diff view or outside it.
Roots carry no warrant fact, as today they carry no
'nonMember', so the ghost root shows no ⊥.
