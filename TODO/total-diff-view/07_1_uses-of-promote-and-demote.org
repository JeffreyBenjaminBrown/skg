Live code and docs also use "promote" in four other senses: lifting the sole top heading of an imported org file to its root ('parse.rs'), turning a viewnode into a deleted-node phantom ('viewnode.rs'), raising a search term to MUST ('docs/COMMANDS-nvim.org'), and two plain-English senses, raising something's prominence ('docs/this-is-awesome.org') and adopting something as a standard ('coding-advice/'). The pair "demote = make write-protected" and "promote = make editable" never occurs in code or docs; it occurs in the historical 'TODO/DONE/local-view-update/' plans under the old names "indefinitive" and "definitive", in one line of 'TODO/DONE/rename-indef-to-writeprotected.org', and in the recent TDV documents ('04_plan-fixes.org', '05_review.org', '07_review.org'). The open TODO files outside 'TODO/DONE/' and 'TODO/total-diff-view/' add the 'affectsParent' sense ('TODO/problems.org'), "focus-promotion" ('TODO/lying-names.org') and an async-to-sync sense ('TODO/from-dot-claude/obsolete-skgnodemap.org'). Terms used below. A /viewnode/ is one node of the tree the server draws into a buffer (an org headline in Emacs); it is a drawing of a stored node, not the stored node itself. An /occurrence/ is one viewnode that shows a given stored node; a node can occur several times in one view. 'affectsParent' is a flag on a viewnode: true means the child is a /member/ of its parent (it belongs to the parent's content list or to the folder's set, and a save reads it as such); false means the child sits under the parent only in the view, and a save does not add it to the parent. Older documents call these two values 'parentIs=Affected' and 'parentIs=Independent', and say "independent" or "non-member" for the second. A /stale/ member is a child marked as a member whose node the graph no longer lists in its parent's list or set. A /write-protected/ occurrence shows no body, accepts no edits, and has no content children drawn under it; older documents call it "indefinitive". An /editable/ occurrence is the opposite; older documents call it "definitive", and a "DVR" (definitive view request) is the user's request to make an occurrence editable. A /phantom/ is a viewnode standing for a node that is absent from the current graph (deleted, historical, or unknown). "TDV" is the total diff view.

* "demote": set a child viewnode's 'affectsParent' to false, keeping it and its subtree in the view instead of deleting it
This meaning turns a member into a non-member: the child stays where it is, with its children, but a save no longer reads it as belonging to its parent. Older documents say "demote to Independent" or "demote to 'parentIs=Independent'" for the same act. The uses fall into four groups by what triggers the act; all four groups set the same flag. (124 + 32 + 4 + 4 = 164 uses.)
