* How to run a plan unattended
This replaces 'jeff-resume-here.org', which is deleted. The runner is
'bash/run-plan-slices.sh'; its header comment says what it takes.
** Before starting
Commit the plan and anything else you want tracked. Every slice's
last commit edits the plan (its DONE keyword rides in that commit,
never in a commit of its own). Tracked files with uncommitted changes
do not stop the script: it takes them for the work a stopped slice
left behind and hands them to that slice's agent to finish and
commit, so commit or stash edits of your own first. The script's
'PLAN' and 'PROGRESS_HEADLINE' variables and its default last slice
name the plan it runs; change them for a new plan. Then, from a plain
shell in the container (claude refuses to nest):
#+begin_example
nohup bash/run-plan-slices.sh > TODO/total-diff-view/run-logs/run.out 2>&1 &
#+end_example
** What runs
One fresh Claude Code session per slice (Opus 5.5, effort high,
permissions bypassed), in order. After each slice the script checks
that the agent marked the slice's headline DONE in the plan, and it
stops at the first slice that did not end that way. It writes under
'run-logs/' in this directory: 'run.out' (its own output; the last
line says how the run ended), 'sessions.log' (one line per slice
start, with the session UUID, and one per finish), and per slice
'slice-N.json' (the raw result), 'slice-N.txt' (the agent's final
message) and 'slice-N.err' (its stderr).
** When every slice is DONE
Review the commits (each message names its plan and slice), run the
three suites yourself, dogfood what the plan built, and read
'progress.org' under the plan's headline, which holds the deviations
the agents chose to record.
** When a slice ended without DONE
The agent stopped for a question; its report is in 'progress.org'
under the plan's headline, and its last message in 'slice-N.txt'.
Answer it in the session that asked, with its context intact:
#+begin_example
claude --resume UUID --dangerously-skip-permissions
#+end_example
with the UUID from 'sessions.log'; let it finish the slice and mark
it DONE inside its last commit. Or rewrite the slice in the plan and
rerun the script, which hands the modified files to a fresh agent as
leftover work. Either way, rerunning the script skips every slice
already DONE; give it a range ('bash/run-plan-slices.sh 2 3') to be
explicit.
** When claude exited nonzero
Read 'slice-N.err'. Usual causes are a network or authentication
failure, or a crash. Resume the same session as above; if it has no
useful context, rerun the script, which starts that slice afresh.
** What is meant to be committed
The plan (its DONE keywords) and the agents' commits. 'progress.org'
is committed by the agents with each slice. 'run-logs/' is
bookkeeping and stays untracked.
