#+title: Jeff, resume here: the unattended run of the current plan

* Before starting it
Commit the plan ('10_plan_still-more.org') and anything else you want
tracked: every slice's last commit edits the plan (its DONE keyword
rides in that commit, never in a commit of its own). Tracked files with
uncommitted changes do not stop the script; it takes them for the work
a stopped slice left behind and hands them to that slice's agent to
finish and commit, so commit or stash edits of your own first. Then,
from a plain shell in the container:
#+begin_example
nohup bash/run-plan-slices.sh > TODO/total-diff-view/run-logs/run.out 2>&1 &
#+end_example

* What runs
'bash/run-plan-slices.sh' runs the slices of [[file:10_plan_still-more.org][10_plan_still-more.org]] in
order, slices 0 to 1, each in a fresh Claude Code session (Opus 5.5, effort
high, permissions bypassed). After each slice the
script checks whether the agent marked that slice's headline DONE in
the plan, and it stops at the first slice that did not end that way.
Everything it writes is under 'run-logs/' in this directory.

* First look: three files
** run-logs/run.out
The script's own output. Its last line tells you how the run ended:
"all requested slices are DONE", "slice N ended without DONE" or
"slice N: claude exited nonzero". A first line "tracked files are
modified and will be handed to the first slice run" means a stopped
slice's work was picked up.
** run-logs/sessions.log
One line per slice start ("slice N  session UUID") and one per slice
finish ("slice N DONE"). The UUID is what you need to resume a session.
** the plan's headlines
#+begin_example
grep '^\*\* ' TODO/total-diff-view/10_plan_still-more.org
#+end_example
Every slice that finished reads "** DONE Slice N: ...".

* If every slice is DONE
Review the commits ('git log --oneline' since your planning commit;
each message names its slice) and run the suites once yourself:
'cargo nextest run', 'bash/emacs-tests.sh', 'bash/nvim-tests.sh'. Edit a
subscribee folder under a write-protected headline and save: the
save is refused. Then read 'progress.org' under its "Still more
fixes" headline: it holds any deviation from the plan
the agents chose to record.

* If a slice ended without DONE
The agent stopped for a question. Its report is in [[file:progress.org][progress.org]] under
"Still more fixes"; its last message is in 'run-logs/slice-N.txt'. The plan
expects no stop.
** Answer it in the session that asked, with its context intact
#+begin_example
claude --resume UUID
#+end_example
Take the UUID from 'run-logs/sessions.log'. Add
'--dangerously-skip-permissions' if you do not want to approve each
tool call by hand. Answer the question, let it finish the slice, and
ask it to mark the slice DONE in the plan inside its last commit.
** Then continue the run
#+begin_example
nohup bash/run-plan-slices.sh > TODO/total-diff-view/run-logs/run.out 2>&1 &
#+end_example
It skips every slice already marked DONE. Give it a range
('bash/run-plan-slices.sh 1 1') to be explicit.

* If claude exited nonzero
Read 'run-logs/slice-N.err'. Usual causes are a network or
authentication failure, or a crash. Resume the same session as above;
if it has no useful context, delete nothing and just rerun the script,
which starts that slice afresh.

* Where things are
- 'run-logs/slice-N.json' is the raw result of each run; 'slice-N.txt'
  is the agent's final message; 'slice-N.err' is its stderr.
- The plan is the specification; 'progress.org' is the agents'
  deviation and stop log; 'run-logs/' is the run's bookkeeping. Of the
  three, only the plan's DONE keywords are meant to be committed.
- The review that produced the plan is [[file:09_review.org][09_review.org]]; the agents were
  told it is background they need not read.
