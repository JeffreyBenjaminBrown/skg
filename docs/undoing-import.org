* Returning imported data to Org
Skg can [[file:COMMANDS.org::#export-org][export selected content to plain Org]]. This produces readable
documents, not a restoration of the original Org-roam files. Keep the
originals if you need their exact structure and metadata.

The current export removes Skg metadata and rewrites ID links as file or
heading links. It does not preserve node IDs, aliases, privacy sections,
subscriptions, overrides, or hides. Shared nodes and cycles can appear as
link leaves rather than repeated subtrees. Reimporting cannot reconstruct
the original graph; the existing Org-roam importer also requires file-level
IDs that this export does not generate.

For import instructions and replacement behavior, see
[[file:COMMANDS.org::#import-org-roam][import-org-roam in the command reference]].
