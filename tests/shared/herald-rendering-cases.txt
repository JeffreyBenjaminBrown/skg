# How each client renders a headline's '(skg ...)' metadata as heralds:
# the displayed text, and the style of each character. One contract,
# two implementations, each tested against these cases:
#   Emacs:  elisp/heralds-minor-mode.el
#           (tests/elisp/test-heralds-minor-mode.el)
#   Neovim: nvim/lua/skg/heralds.lua
#           (tests/nvim/heralds_spec.lua)
# Both use the served rule table pinned in tests/shared/herald-rules.sexp.
#
# Format: a case begins with a line '==== NAME', followed by one line of
# metadata, then '---- text: ' and the displayed text, then '---- styles: '
# and the styles of the text's characters, in order, as runs STYLE*COUNT.
# A style is a name from shared/herald-styles.json, or '-' for an
# unstyled character, such as the space between two heralds. Lines
# before the first case are comments.
