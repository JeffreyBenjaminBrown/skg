* PURPOSE
Writes the call tree of one function of 'server/' (default 'main') as
an Org file, 'output/FUNCTION.org' in this folder: each headline is a
function, and its children are the functions it calls. It also writes
'db/functions.csv' and 'db/calls.csv', every function of 'server/'
with its file and length, and every caller-callee pair. The header of
'call-graph.rs' says the rest.
* USAGE
This was copied from the .rs file:
** Generate a call tree for a function:
   cargo run -p call-graph [-- function_name]
** Regenerate all existing call trees:
   cargo run -p call-graph --bin call-graph-regen
